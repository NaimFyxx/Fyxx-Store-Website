Appy Hour — element & state spec sheet

Every Appy Hour element in every state, rendered from the real theme CSS (assets/appy-hour.css) and the real snippet markup. Static and self-contained: the countdown is frozen at 32:10, the card artwork is embedded, and nothing calls the live store. Each element is shown in a device frame so the 749px mobile breakpoint renders truthfully; desktop frames are zoomed to fit and labelled with their real viewport width. Prices shown use a 13% example (regular 60% navy strike-through, Appy Hour price bold navy); the live value comes from the window metafield.
